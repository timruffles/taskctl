# Agent workflow

Use the [taskctl skill](../skills/taskctl/SKILL.md) when choosing or claiming work, recording progress, replacing stale definitions, coordinating agents, or recovering interrupted work.

The skill contains the core workflow and points to detailed instructions for supersession, notifications and recovery only when those operations are needed. Copy the complete `skills/taskctl` directory when installing it in an agent's skill directory so the references remain available.

For a human's setup and everyday inspection commands, read the [README](../README.md).
