# Agent workflow

Use the [taskctl skill](../skills/taskctl/SKILL.md) when choosing or claiming work, recording progress, replacing stale definitions, coordinating agents, or recovering interrupted work.

The skill is an activation index. It routes to coordination, inspection, working, supersession, notifications, hooks or recovery instructions only when needed. Copy the complete `skills/taskctl` directory when installing it in an agent's skill directory so the references remain available.

For a human's setup and everyday inspection commands, read the [README](../README.md).
